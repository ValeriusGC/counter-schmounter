## Синхронизация

Счётчик синхронизируется через собственный сервер **ulsync**, а не через таблицу Supabase.
**Supabase** остаётся только поставщиком входа и сессии.

**Без входа** работа локальная: плюс пишет только журнал на устройстве, ошибок сети из-за sync нет.

**Живой ленты нет:** второе устройство увидит плюс после своего обмена (холодный старт / следующий плюс, когда сеть есть). Это ограничение шага 15, не баг.

### Адрес сервера

Задаётся при запуске:

```bash
--dart-define=ULSYNC_BASE_URL=http://...
```

Значение по умолчанию в коде — `http://10.0.2.2:8080` (loopback машины-хозяина **для Android-эмулятора**).

| Платформа | Типичный URL |
|-----------|----------------|
| Android-эмулятор | default, без dart-define |
| iOS-симулятор, macOS | `http://127.0.0.1:8080` |
| Физическое устройство в LAN | `http://<IP-машины>:8080` (сервер слушает `0.0.0.0:8080`) |

### Запуск приложения

По-прежнему нужны `SU` и `SAK` (Supabase):

```bash
# окно 1 — Android emulator
cd /Users/vvk/AndroidStudioProjects/r/counter_schmounter
flutter run -d emulator-5554 \
  --dart-define=SU="$SU" \
  --dart-define=SAK="$SAK"

# окно 2 — iOS simulator
cd /Users/vvk/AndroidStudioProjects/r/counter_schmounter
flutter run -d iPhone \
  --dart-define=SU="$SU" \
  --dart-define=SAK="$SAK" \
  --dart-define=ULSYNC_BASE_URL=http://127.0.0.1:8080
```

### Сервер и JWT

- В бою сервер за **https** — настройка обратного прокси, см. `ulsync-server/docs/CONFIG.md`.
- Debug Android разрешает cleartext HTTP; iOS — только local networking (`NSAllowsLocalNetworking`).
- JWKS URL сервера: `$SU/auth/v1/.well-known/jwks.json` (не `dev_hs256_secret` для входа из приложения).
