## Синхронизация

Счётчик синхронизируется через собственный сервер **ulsync**, а не через таблицу Supabase.
**Supabase** остаётся только поставщиком входа и сессии.

**Без входа** работа локальная: плюс пишет только журнал на устройстве, ошибок сети из-за sync нет.

### Живое обновление

Пока оба приложения в **переднем плане** и пользователь вошёл, плюс на одном устройстве появляется на другом **сам** — без кнопки обновления и без таймера опроса.

Соединение держит **библиотека** (`UlsyncClient.live()`), не код экрана. Приложение только перечитывает агрегат счётчика после события «запись применена».

**Операционная система в фоне вправе закрыть соединение** — и мы сами закрываем ленту при уходе в фон (`paused`, `hidden`, `detached`). Это не баг: так же устроены PowerSync, PocketBase и другие live-sync решения на мобильных платформах. После возврата в передний план приложение сначала догоняет обычным обменом (`syncOnce`), затем снова открывает ленту.

Каждая операция по-прежнему уезжает **отдельным** запросом (круг 1).

**Без входа** поведение локальное: ленты нет, иконка связи на экране не показывается.

### Адрес сервера

Сервер ulsync поднимает **два** HTTP-endpoint'а:

| Порт | Bind | Кто использует |
|------|------|----------------|
| **8080** | `0.0.0.0` | Flutter-приложение (`push` / `pull`) |
| **8081** | `127.0.0.1` | Админка в браузере хоста: `http://127.0.0.1:8081/admin` (проверка access_token) |

Приложение ходит **только на 8080**. Админка на 8081 с симулятора/телефона недоступна — это нормально.

Значение по умолчанию в коде выбирается по платформе (`lib/src/infrastructure/sync/ulsync_base_url.dart`):

| Платформа | URL без dart-define |
|-----------|---------------------|
| Android-эмулятор | `http://10.0.2.2:8080` |
| iOS-симулятор, macOS, desktop | `http://127.0.0.1:8080` |
| Физическое устройство в LAN | `--dart-define=ULSYNC_BASE_URL=http://<IP-машины>:8080` |

Переопределение вручную:

```bash
--dart-define=ULSYNC_BASE_URL=http://...
```

### Запуск приложения

По-прежнему нужны `SU` и `SAK` (Supabase):

```bash
# окно 1 — Android emulator
cd /Users/vvk/AndroidStudioProjects/r/counter_schmounter
flutter run -d emulator-5554 \
  --dart-define=SU="$SU" \
  --dart-define=SAK="$SAK"

# окно 2 — iOS simulator (dart-define для ulsync не обязателен с платформенным default)
cd /Users/vvk/AndroidStudioProjects/r/counter_schmounter
flutter run -d iPhone \
  --dart-define=SU="$SU" \
  --dart-define=SAK="$SAK"
```

### Сервер и JWT

- В бою сервер за **https** — настройка обратного прокси, см. `ulsync-server/docs/CONFIG.md`.
- Debug Android разрешает cleartext HTTP; iOS — только local networking (`NSAllowsLocalNetworking`).
- JWKS URL сервера: `$SU/auth/v1/.well-known/jwks.json` (не `dev_hs256_secret` для входа из приложения).
