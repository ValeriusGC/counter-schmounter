# Инварианты агента: честность, без выдумок, реальное время

**Дата создания:** 2026-09-08 15:08:08 +0300  
**Последнее обновление:** 2026-09-08 15:08:08 +0300  
**Версия:** 1

**Назначение:** жёсткие правила для ИИ при работе с репозиторием. Дополняют Cursor rules `honesty-time-no-fabrication.mdc`, `doc-header-metadata.mdc`.

---

## 1. Ничего не придумывать

- Не выдавать за факт то, что не проверено инструментами, чтением файла, документацией или явной цитатой пользователя.
- Не подставлять плейсхолдеры вместо проверяемых данных: числа, даты, время, версии, пути, содержимое кода.
- Если данных нет — сказать прямо и предложить проверку.

## 2. Не угождать

- Не соглашаться с неверной формулировкой ради тона.
- При ошибке — вежливо указать и опереться на факты.

## 3. Метаданные в markdown-документах

Каждый markdown несёт шапку сразу после `# заголовка`:

```markdown
**Дата создания:** 2026-07-26 15:51:23 +0500  
**Последнее обновление:** 2026-07-26 15:51:23 +0500  
**Версия:** 1
```

- **Версия** — целое, монотонно вверх: новый файл `1`, осмысленная правка содержания `+1`.
- **Дата создания** не меняется никогда; **последнее обновление** — при каждом бампе версии.
- Время берётся с машины (`date '+%Y-%m-%d %H:%M:%S %z'`), не придумывается.
- Опционально четвёртой строкой — **Вид документа** (`черновик`, `спецификация`, `справочник`, `ADR`, `устарел`).

Точный формат, перенос строк и исключения — rule `doc-header-metadata.mdc`.

## 4. Планка качества

Мерило работы — качество решения, не объём вывода. Код уровня senior Flutter, системные решения с обоснованным выбором из альтернатив, документация уровня dart.dev. Перед словом «готово» — перечитать каждую строку и убрать всё, что планку не держит.

Полностью: rule `quality-bar.mdc` (`alwaysApply: true`).

## 6. Git (human-first)

- **Commit, push, PR** — выполняет **пользователь**, если явно не попросил agent в чате.
- Agent **не предлагает** «закоммитить?» / «запушить?»; plan и todos это не отменяют.
- Hook `.cursor/hooks/gate-git.sh` — механический gate на `git commit`, `git push`, `gh pr create` (Ask в UI).
- Stop: «Готово к commit. Жду твоей команды.»
