## Формат записи

Единая таблица во всех файлах:

```markdown
| Имя | Путь | Назначение | Когда использовать |
|-----|------|------------|-------------------|
```

- **Имя** — класс, функция или краткий идентификатор
- **Путь** — относительно корня репозитория (`lib/...`)
- **Назначение** — 1–2 предложения для AI
- **Когда использовать** — триггеры выбора (не дублировать «Назначение»)

## Когда добавлять строку

- Создан **новый** shared-артефакт (виджет в `lib/ui/shared/`, утилита в `lib/core/` и т.д.)
- Существующий артефакт **существенно расширен** — обновить описание
- При рефакторинге **переименован/перенесён** — обновить путь

## Когда НЕ дублировать

- Экранные private-виджеты (`_Foo`) — не в реестр
- Одноразовые виджеты внутри одного экрана — не в реестр
- Generated-файлы (`*.g.dart`, `*.freezed.dart`) — не в реестр

## Поддержка

Реестры — часть Definition of Done. PR с новым shared-кодом без записи в реестре — неполный.
