## v0.1.6 - 2026-09-09

- Живое обновление переведено с Supabase Realtime на собственный сервер через `ulsync`.
- В фоне соединение не держится; после возврата в передний план догонка обычным обменом (`syncOnce`), затем снова открывается лента.
- Каждая операция всё ещё уезжает отдельным запросом.

## v0.1.5 - 2026-09-08

- Синхронизация счётчика переведена с таблицы Supabase на собственный сервер через пакет `ulsync` (path-зависимость `../ulsync-dart`).
- Каждая операция пока уезжает отдельным запросом; пачек конвертов нет.
- Живой ленты нет: второе устройство догоняет обменом по требованию (debounce после плюса, initial sync при старте с сессией).
- Без входа поведение локальное, как раньше.
- Зависимости: `path_provider` 2.1.6 (рабочая), `sembast` 3.8.9+1 (только dev_dependencies для тестов).
